# 🚀 DevMark Agency Landing Page

A modern, responsive landing page built with **Jekyll**, designed to showcase a digital marketing agency focused on generating leads and growing businesses.

## 🌐 Live Demo

👉 https://makerting-page.vercel.app

---

## 📌 Overview

This project demonstrates a clean, professional landing page using a **modular Jekyll architecture** and **mobile-first SCSS styling**.

It is structured to be easily scalable and maintainable, following best practices for front-end development.

---

## 🛠️ Tech Stack

* **Jekyll** – Static site generator
* **Liquid** – Templating engine
* **SCSS (Sass)** – Modular styling
* **HTML5** – Semantic structure
* **Responsive Design** – Mobile-first approach
* **Vercel / GitHub Pages** – Deployment

---

## 📂 Project Structure

```
.
├── _layouts        # Layout templates
├── _includes       # Reusable components (header, hero, etc.)
├── _sass           # SCSS partials
├── assets
│   ├── css         # Main compiled styles
│   └── images      # Image assets
├── index.html      # Entry point
├── _config.yml     # Jekyll configuration
```

## 🚀 Getting Started

### 1. Install dependencies

```bash
bundle install
```

### 2. Run locally

```bash
bundle exec jekyll serve
```

### 3. Open in browser

```
http://127.0.0.1:4000/
```
